# Changelog

## 1.0.0

First public release.

- Shelf and jukebox styles, a box that opens and a disc that spins when playing.
- Steam games and any `.desktop` file, with bulk import.
- Custom art (spine, cover, logo and disc), cutting full box art and discs from templates, and Steam art already on the computer.
- Sounds per moment and per disc, with your own files.
- Keyboard shortcut and gamepad (with Python 3).
- Hides only the windows on the widget's monitor and keeps Steam minimized during the animation.
- Compatibility mode for Qt older than 6.9.
- Export and import the game list.
- Test mode.
- English and Spanish.
